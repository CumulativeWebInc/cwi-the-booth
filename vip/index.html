How attribution works

  1. Share your link. /vip/?ref=<handle> — it lands here, then sends the visitor to the sandbox with your handle attached.
  2. They buy credits. The credit_purchase ledger entry carries "referrer": "<handle>" — recorded by the same production ledger code (ledger-core.js) the sandbox runs.
  3. Audit it yourself. Download the receipts (.jsonl), run the chain verify, grep for referrer. The referralCounts() read helper tallies attributed equips per handle — that's how the kill rule below is measured.

Why the query-param form? GitHub Pages is static — there is no per-handle file to create. vip/?ref=<handle> is the honest static-site equivalent of vip/<handle>; the sandbox honors ?ref= directly too.
